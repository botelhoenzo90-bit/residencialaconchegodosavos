# Vídeos do residencial

Coloque nesta pasta os vídeos que serão exibidos um abaixo do outro na página.

Formato recomendado: `.mp4` (H.264), de preferência otimizados para carregamento rápido.

Sugestão de nomes: `01-apresentacao.mp4`, `02-rotina-e-atividades.mp4`, `03-conheca-o-espaco.mp4`.

Use apenas vídeos autorizados para divulgação. Os arquivos colocados aqui ainda precisam ser conectados aos componentes da página para aparecerem no site.

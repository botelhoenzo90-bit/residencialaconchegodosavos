# Fotos do espaço físico

Coloque nesta pasta as fotos reais dos ambientes do Residencial Aconchego dos Avós para o primeiro carrossel.

Formatos recomendados: `.webp`, `.jpg` ou `.png`.

Sugestão de nomes: `01-fachada.jpg`, `02-sala-de-convivencia.jpg`, `03-quartos.jpg`, `04-patio.jpg`.

Use nomes curtos, sem espaços ou acentos. Esta pasta é reservada às fotos dos ambientes.

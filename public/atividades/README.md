# Fotos das atividades

Coloque nesta pasta as fotos das atividades realizadas pelos residentes para o segundo carrossel.

Formatos recomendados: `.webp`, `.jpg` ou `.png`.

Sugestão de nomes: `01-atividade-em-grupo.jpg`, `02-musica.jpg`, `03-artesanato.jpg`, `04-momento-de-convivencia.jpg`.

Use apenas fotos autorizadas para divulgação e nomes curtos, sem espaços ou acentos.
